# GS Suite

Portal único de acceso a las aplicaciones de Gestión Social APPLUS+ (GS Docs, GS Firmas, GS Editor, GS Diagnósticos, GS Alumbrado Público, GS Studio, GS Agenda).

Página estática, sin build. Para agregar o cambiar una app, edita el catálogo `GRUPOS` al inicio del script de `index.html`. Las direcciones también se pueden cambiar desde el engranaje ⚙ de la app (se guardan en el dispositivo).
